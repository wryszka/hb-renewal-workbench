# Demo run-sheet — HB Renewal Workbench

**Audience framing:** present in their process order — receive → verify → check the math → challenge → decide → refresh → learn. The platform words (tables, functions, Delta, Unity Catalog) live in **Q&A**, never in a SAY line.
**Runtime:** ~25 min demo + 10 min Q&A. Each beat's title shows its minute budget.
**If compressed, cut in this order:** cut **10**, then **3**, then **8**. **NEVER cut 2, 5, 7.**
**Q&A:** presenter answers are in `DEMO_QA.md` (in-app: Presenter tab when `PRESENTER_MODE=true`). IF-ASKED lines point to Q&A item numbers.

**Read each beat as:** **GO** (where to click) · **DO** (the one action) · **SAY** (audience words, ≤20 words, say the **bold** numbers) · **IF ASKED / IF FAILS** (fallback + Q&A #).

## Demo files (synthetic, in `demo_files/`)

Generated by `data/make_carrier_file.py`; invented carrier **Meridian Assurance** / employer **Harborview Logistics**. The renewal exhibit carries **6 tabs** — Renewal Summary · Claims Experience · High Cost Claimants · Rate Development · Benefits Overview · Detailed Rates — mirroring a real carrier exhibit.
- `meridian_harborview_2026H2.xlsx` — clean → **active** (beats 2, 4, 5)
- `meridian_brokenlayout.xlsx` — malformed → **quarantine** (beat 3)
- `meridian_harborview_2026H2_v2.xlsx` — trend changed → supersession
- `meridian_harborview_2026H2_month13.xlsx` — one fresh month → **reforecast** (beat 6)

**Behind the scenes (if asked "what's actually happening?"):** on Ingestion, every pipeline block and the "Behind the scenes — real assets" panel link straight to the live Volume, Job, tables, function, Genie and dashboard. Open one to show it.

**0 · The problem (1m)**
- **GO:** Before you open the app.
- **DO:** Set it up in one line.
- **SAY:** "Every renewal, you negotiate inside the carrier's spreadsheet — then throw the work away. No record, no benchmark."
- **IF ASKED:** Is this a product? → Q&A #15.

**1 · Daily view — the desk today (1m)**
- **GO:** Overview → Daily view.
- **DO:** Point at the KPI tiles + "needs attention".
- **SAY:** "This is the renewal desk today — **53** in the book, **2** need a human, and what we've saved negotiating."
- **IF ASKED:** Where do the numbers come from? → Q&A #1.

**2 · Receive the file — ingest (3m)** *(never cut)*
- **GO:** Pipeline → Ingestion → **↥ Upload & ingest** → drop `meridian_harborview_2026H2.xlsx` → click the file row to open the drill-down.
- **DO:** Watch two paths extract + reconcile; show the field-by-field agreement.
- **SAY:** "The carrier emails a spreadsheet — no feed. Two independent readers pull every number and must agree: **17 of 17**."
- **IF ASKED / FAILS:** Upload ~10 s (Job ~57 s); hero is pre-seeded active if upload stalls. Extraction correct? layout changes? → Q&A #6, #3.

**3 · Quarantine — the control working (1m)**
- **GO:** Ingestion → **↥ Upload & ingest** → drop `meridian_brokenlayout.xlsx`.
- **DO:** Show status **quarantined** + the field diff; no rows land.
- **SAY:** "Wrong layout? It's held for a human with the exact diff — the pipeline refuses rather than guesses."
- **IF ASKED / FAILS:** pre-seeded twin `DOC-Q900` if the drop misbehaves. → Q&A #3.

**4 · It matches your sheet (2m)**
- **GO:** Pipeline → Book → the Harborview row → opens Renewal Workspace (build-up on the left).
- **DO:** Read the build-up line-by-line against their exhibit.
- **SAY:** "Step one: we reproduce their math exactly — **26.9%**, to the decimal. Step two: now we ask if it's fair."
- **IF ASKED:** anchor "matches your sheet" on the blended action, not the monthly tab. Manual rate? math location? → Q&A #2, #9.

**5 · Negotiate & decide — the centre piece (5m)** *(never cut)*
- **GO:** Renewal Workspace → right-hand **Levers** → **Annual Trend** → set **7.0%** → the Compare strip updates → **💾 Save scenario** → name **"Trend to book"**, reason **"Carrier trend 5.2pts above our book median"** → Save → appears in **Compare** and in **Audit**.
- **DO:** Move trend to 7.0%; save with that exact name + reason.
- **SAY:** "Their trend is **12.2%**; our book says **7.0%** — five points rich. Hold it to book: **26.9% → 23.0%**, about **$183k** a year."
- **THEN:** **✎ Draft exec summary** (the Deal Summariser writes a client-ready note from the saved position).
- **SAY (summary):** "And the client summary writes itself from the decision — in our words, not the carrier's."
- **IF ASKED:** save requires a name + reason (that's the governance); agents advise, humans decide. → Q&A #1, #2, #13, #16.

**6 · Reforecast — fresh data, no rebuild (2m)**
- **GO:** Ingestion → **↥ Upload & ingest** → drop `meridian_harborview_2026H2_month13.xlsx` → back to Renewal Workspace (banner appears).
- **DO:** Show the "fresh data available" banner on the open renewal.
- **SAY:** "Fresh month in — same pipeline, no rebuild. Settled at **23.0%**; the workbench now flags the data's moved. Side-by-side recompute is **V2**."
- **IF FAILS:** skip forward, mention it verbally, return if time (it's mid-demo, not the closer). → Q&A #10.

**7 · Benchmarks — your own book (2m)** *(never cut)*
- **GO:** Renewal → Benchmarks.
- **DO:** Point at padder vs fair + the negotiation delta + value negotiated.
- **SAY:** "This trend benchmark is built from your own retained deals — Cascade runs rich (**~8%**), Evergreen fair (**~5%**)."
- **IF ASKED:** derived from decisions, not bought or hardcoded; how many until credible? → Q&A #1, #8.

**8 · Agents — the reviewer (2m)**
- **GO:** Intelligence → Agents.
- **DO:** Show the Reviewer's findings (the Summariser was already seen in beat 5).
- **SAY:** "The reviewer challenges each assumption and flags what's worth pushing on — it advises, you decide."
- **IF ASKED:** can agents decide/write? → Q&A #13, #19.
